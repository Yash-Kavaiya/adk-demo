# BookForge Go - Installation & Setup Guide

## Prerequisites Installation

### 1. Install Go

**Windows:**
```powershell
# Download and install Go from official website
# https://go.dev/dl/

# Or use Chocolatey
choco install golang

# Verify installation
go version  # Should show go1.23 or later
```

**macOS:**
```bash
# Using Homebrew
brew install go

# Verify
go version
```

**Linux:**
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install golang-go

# Fedora/RHEL
sudo dnf install golang

# Verify
go version
```

### 2. Install Google ADK Go

```bash
cd bookforge-go

# Initialize module (if not done)
go mod init github.com/yourusername/bookforge-go

# Add ADK Go v2
go get google.golang.org/adk/v2

# Fetch all dependencies
go mod tidy
```

### 3. Get Google API Key

1. Visit https://aistudio.google.com/app/apikey
2. Create a new API key
3. Copy the key

### 4. Configure Environment

**Windows (PowerShell):**
```powershell
# Create .env file
Copy-Item .env.example .env

# Edit .env and add your API key
notepad .env

# Load environment
Get-Content .env | ForEach-Object {
    if ($_ -match '^([^=]+)=(.*)$') {
        [System.Environment]::SetEnvironmentVariable($matches[1], $matches[2], 'Process')
    }
}
```

**Windows (Command Prompt):**
```cmd
copy .env.example .env
notepad .env
REM Then run env.bat to load variables
env.bat
```

**Unix/Linux/macOS:**
```bash
cp .env.example .env
# Edit .env with your favorite editor
nano .env

# Load environment
source .env
# Or
export $(cat .env | xargs)
```

## Quick Start

### 1. Build the Agent

```bash
cd bookforge-go

# Build binary
go build -o bookforge agent.go

# Or run directly
go run agent.go
```

### 2. Run Command-Line Interface

```bash
# Make sure environment is loaded
source .env  # Unix/Mac
# OR
.\env.bat    # Windows

# Run the agent
go run agent.go

# Or use built binary
./bookforge  # Unix/Mac
.\bookforge.exe  # Windows
```

When prompted, paste your YouTube channel URL.

### 3. Run Web Interface

```bash
go run agent.go web api webui
```

Then open http://localhost:8080 in your browser.

## Troubleshooting

### Issue: `go: command not found`

**Solution:** Go is not installed or not in PATH.

**Windows:**
```powershell
# Check if Go is installed
where go

# If not found, install from https://go.dev/dl/
```

**Unix/Mac:**
```bash
which go

# If not found
# macOS: brew install go
# Linux: sudo apt install golang-go
```

### Issue: `cannot find package google.golang.org/adk/v2`

**Solution:** Run `go mod tidy` to fetch dependencies.

```bash
cd bookforge-go
go mod tidy
```

### Issue: `GOOGLE_API_KEY environment variable must be set`

**Solution:** Create and load .env file.

```bash
# Copy example
cp .env.example .env

# Edit and add your key
nano .env

# Load environment
source .env
```

### Issue: Module version conflicts

**Solution:** Update go.mod with correct versions.

```bash
# Update all dependencies
go get -u ./...
go mod tidy

# Or update specific package
go get google.golang.org/adk/v2@latest
```

### 2. Building

```bash

go build -o bookforge agent.go

# Production build with optimizations
go build -ldflags="-s -w" -o bookforge agent.go

# Cross-compile for different platforms
GOOS=linux GOARCH=amd64 go build -o bookforge-linux agent.go
GOOS=darwin GOARCH=arm64 go build -o bookforge-mac-arm agent.go
GOOS=windows GOARCH=amd64 go build -o bookforge.exe agent.go
```

### 3. Testing

```bash
# Run tests
go test ./...

# Run with coverage
go test -cover ./...

# Verbose output
go test -v ./...

# Test specific package
go test ./tools
```

### 4. Formatting and Linting

```bash
# Format code
go fmt ./...

# Run linter (install golangci-lint first)
golangci-lint run

# Check for suspicious code
go vet ./...
```
